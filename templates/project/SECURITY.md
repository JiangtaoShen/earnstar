# Security policy

## Supported versions
Security fixes go into the latest release.

## Reporting a vulnerability
Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include the version, the steps to reproduce, and the impact you see.

You should get a first response within 7 days. Once a fix is released, the advisory will credit you unless you prefer otherwise.
